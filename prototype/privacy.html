01About this draft

This is a technical description of the current local IIT Bombay Sports redesign, reviewed on 2 November 2026. It is not an approved institutional privacy policy. The responsible institute team must supply or approve the final text before publication.

The statements below describe this local implementation. They do not establish the practices of the current sports website, the institute’s other systems or the eventual hosting provider.

02Public archive content

Sports information, names, published contacts, photographs, player records, calendar entries and Yearbook messages come from the saved public sports website and its linked source material. The archive was captured on 18 October 2026. Source dates and gaps are stated on the relevant pages.

The Player Database contains 126 archived public records; it is not a live or exhaustive roster. The archive contains no authenticated private certificate list, submitted grievances or private booking records. For a correction request, use the contact routes; a dedicated institutional privacy contact is still to be confirmed.

03Forms and local drafts

The new booking, feedback and prediction interfaces prepare local reviews. Their code does not send form text, names, roll numbers, LDAP contacts, images or predictions to a service. Feedback image checks and previews use the selected file in page memory and a browser object URL; no upload occurs.

No account is created and no password or certificate authentication token is requested. The new pages do not deliberately persist form drafts in localStorage, sessionStorage, cookies or a database. Browser autofill, page restoration and caching follow the visitor’s browser settings. Use the clear controls when finished with personal details.

Booking date, court and source-session preferences may appear in the URL. Directory, calendar and Yearbook search text and filters, and Council record links, can also appear in page addresses and browser history. Personal booking and report fields are not encoded into URLs by the new forms.

04Storage and preferences

The homepage uses one sessionStorage value, iitb-sports-opening-cycle-v2, to cycle between seven opening sports illustrations in the same browser tab. The value is a numeric scene index, not an account or contact identifier. The illustration still works when storage is unavailable.

Motion follows the browser’s reduced-motion preference and page controls. These controls do not create a user account. No analytics, advertising tracker or application cookie has been added to this local redesign. Actual hosting logs, infrastructure cookies and retention settings remain unconfirmed.

05Fonts, assets and external services

Faktum font files, official marks, local photographs, scene models, textures and JavaScript libraries are served with the site. This implementation does not request Google Fonts. Court connection checks read a same-site configuration file that declares the service unavailable; they do not check live slots.

Current booking, certificate and contact pages, social profiles, maps where linked, and Yearbook attachments can open external destinations when selected. Those destinations receive their own requests and apply their own practices. A prepared certificate-verification link includes the entered reference in the destination address only when that link is opened.

06Before publication

Institutional review must resolve the following details. This draft does not assign them to a person or invent a retention period.

  • Responsible website operator and privacy contact.
  • Hosting providers, request logging, retention, access controls and request-handling process.
  • Any production booking, feedback, authentication, certificate or prediction integration and the information it processes.
  • Image handling, recipient visibility, deletion procedures and any consent or notice required by the institution.
  • Approval of published contact, player and Yearbook data, and a current correction/removal route.
