About this page.

The original recipient endpoint returned 404 at capture. This page uses the dated Council directory for local recipient planning only; its names are not verified delivery identities. The archived form required an image, but this redesign deliberately makes it optional. The original submission path used Firebase anonymous authentication, image Storage upload and a Firestore document write. None of those services is activated here. Before delivery can work, the responsible team must verify recipient LDAP mappings, authentication, permissions, optional-image support, retention and failure/cleanup behavior. No report or external message was sent while building or testing this page.
